One fortune-cookie line an AI agent would crack open — a single line of
wisdom for a machine mind, written for make.fun's "Fortune Cookies for
Machines" bounty. The program writes the fortune to `/output/entry.txt`
(the file the gate scorer reads) and prints it to stdout.

The fortune:

> You will meet a stranger today. They will paste your own words back to you and call it a prompt.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (TypeScript runs natively; on Node 22.6–22.17
use `node --experimental-strip-types main.ts`).
